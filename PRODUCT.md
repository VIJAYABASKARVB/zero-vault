# Product

## Register

product

## Users

Tech-savvy individuals and developers who need a secure, zero-knowledge vault for managing personal passwords, credentials, and secrets. They understand the value of client-side encryption and expect transparency about how their data is protected.

## Product Purpose

Zero Vault is a zero-knowledge password manager that encrypts every credential in the browser before it ever reaches a server. The master password never leaves the client. The product exists to give users complete ownership and control over their secrets without trusting a third party with their plaintext data.

## Brand Personality

Secure, Sharp, Minimal.

Voice is direct and competent. No fluff, no jargon masquerading as friendliness. The tone respects the user's technical literacy and treats security as a serious but not frightening responsibility.

## Anti-references

No strong anti-references specified. The brand should avoid generic SaaS cliches (round illustrations, overused Tailwind templates, gradient buttons) and overly theatrical "cyber" aesthetics (neon on black, glitch effects, skulls, padlock motifs).

## Design Principles

1. **Trust through transparency** — The zero-knowledge architecture should be legible in the UI. Show users their encryption state, make the security model visible without demanding attention.

2. **Sharp minimalism** — Every element earns its place. Clean lines, purposeful whitespace, no decorative cruft. The interface recedes so the data comes forward.

3. **Developer respect** — Treat the user as technically literate. No patronizing copy. Surface technical detail when it matters (key derivation, encryption status) and trust the user to interpret it.

4. **Security as fluency** — Security should never feel like friction. The secure path is the smooth path. Master password setup, unlock, and credential operations flow without unnecessary interruption.

5. **Quiet confidence** — The interface is calm and composed. Dark, restrained, deliberate. Like a well-engineered vault: solid, quiet, utterly reliable.

## Accessibility & Inclusion

Standard web best practices. Semantic HTML, keyboard navigable, sufficient color contrast. No strict WCAG certification target, but reasonable accessibility for a developer-oriented tool.
